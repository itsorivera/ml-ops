# Model Size Reduction Techniques

## Model Compression

Model compression is a common technique used to reduce the size of a model's data without significantly impacting its predictive accuracy. Key compression techniques include:

*   **Pruning:** This technique involves removing the least important parameters or nodes from a model.

![Pruning](/assets/2.3.4_modelSizeReductionTe.png)
*   **Quantization:** This method changes the representation of weights within the model to a more space-efficient format. For example, converting a 32-bit floating-point representation to an 8-bit integer representation.
![Quantization](/assets/2.3.4_modelSizeReductionTe%20(1).png)
*   **Knowledge Distillation:** In this process, a larger "teacher" model transfers its knowledge to a smaller "student" model. The student model is trained on the same dataset as the teacher, but it also learns from the teacher's understanding of the data.

![Knowledge Distillation](/assets/2.3.4_modelSizeReductionTe%20(2).png)

## A Deeper Look: Iterative Model Pruning

Iterative model pruning is a specific method to reduce a model's size while preserving its performance. The core idea is to identify and remove less useful weights during the training process. Over several iterations, some weights become more influential than others. The goal is to eliminate the non-essential ones.

### Steps for Iterative Model Pruning

Here is a step-by-step guide to the iterative model pruning process:

1.  **Start the Initial Training Job:**
    Begin by training the original, unpruned model. This establishes a baseline for model performance and provides the necessary data for the pruning process.

2.  **Gather Model Internals:**
    Collect and analyze the model's weights, gradients, biases, and activation outputs from the training process. These values are crucial for calculating the importance of each parameter.

    !["Iterative Model Pruning"](/assets/2.3.4_iterativeModelPrunin.png)

3.  **Compute Filter Ranks:**
    Calculate the importance or relevance of each set of parameters (filters) in the model. Each filter is assigned a rank to identify the least important ones. Removing filters with the lowest rank is less likely to negatively impact the model.

    ![Filter Ranking](/assets/2.3.4_iterativeModelPrunin%20(1).png)

    To determine which weights to prune, you can use the following evaluation methods:
    *   **Weight Magnitude:** Remove weights if their absolute value is below a specified threshold.
    *   **Average Activation:** If a neuron remains mostly inactive during training, the weights associated with it are likely less relevant.

4.  **Prune Low-Ranking Filters:**
    Prune the least important filters by removing a specified percentage of the lowest-ranking ones from the model. The pruning threshold can be adjusted based on the desired trade-off between model size and performance.

    ![Prune Low-Ranking Filters](/assets/2.3.4_iterativeModelPrunin%20(2).png)

5.  **Set New Weights:**
    After pruning, update the model's weights to reflect the changes. This may involve redistributing the remaining weights or fine-tuning the pruned model on the training data to recover any lost accuracy.

    ![Set New Weights](/assets/2.3.4_iterativeModelPrunin%20(3).png)

6.  **Iterate with the Pruned Model:**
    Start a new training job with the pruned model. The model will adapt to its new, more compact architecture. Monitor performance, training time, and inference speed to ensure the pruning has achieved the desired results without a significant drop in performance.

### Key Considerations

*   **Pruning Aggressiveness:** Aggressive pruning can lead to an unacceptable drop in model performance. It is best to prune in small increments and continuously monitor the impact.
*   **Monitoring:** Carefully monitor metrics throughout the process to verify that the pruning achieves the desired results without significantly compromising the model's performance.
