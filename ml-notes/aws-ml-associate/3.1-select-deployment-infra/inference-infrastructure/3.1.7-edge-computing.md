# Optimización de Despliegues con Edge Computing

## 1. ¿Qué es Edge Computing?

**Edge Computing** es la práctica de procesar datos en el "borde" de la red, es decir, lo más cerca posible de donde se generan. En lugar de enviar toda la información a un centro de datos centralizado o a la nube, el cómputo se realiza localmente en el dispositivo.

### Beneficios Clave
- **Menor Latencia**: Las decisiones se toman en milisegundos, crucial para aplicaciones en tiempo real.
- **Mayor Eficiencia**: Se reduce la cantidad de datos que viajan por la red, ahorrando ancho de banda y costos.
- **Operación Offline**: Los dispositivos pueden seguir funcionando incluso sin conexión a Internet.

### Tipos de Dispositivos Edge
- Smartphones, tablets y wearables.
- Equipos industriales y de manufactura.
- Cámaras de vigilancia y sistemas de seguridad.
- Sistemas automotrices y de transporte.
- Sensores y gateways de Internet of Things (IoT).

## 2. Arquitectura: El Rol de la Nube y el Edge

Edge Computing no elimina la nube, sino que redefine las responsabilidades de cada componente.

### Modelo Tradicional (Sin Edge)
1.  **Dispositivo/Sensor**: Captura el dato.
2.  **Envío a la Nube**: El dato viaja a un servidor central.
3.  **Procesamiento en la Nube**: Un modelo de Machine Learning analiza el dato.
4.  **Respuesta al Dispositivo**: La nube envía la acción de vuelta.

*   **Resultado**: Proceso lento (segundos), vulnerable a problemas de conectividad.

### Modelo con Edge Computing
1.  **Dispositivo/Sensor**: Captura el dato y lo procesa localmente con un modelo de ML integrado.
2.  **Acción Inmediata**: El dispositivo ejecuta la acción requerida al instante.

*   **Resultado**: Proceso ultra-rápido (milisegundos), autónomo y resiliente.

### ¿Qué Tareas se Quedan en la Nube?

| Tarea | ¿Dónde se Realiza? |
| :--- | :--- |
| **Entrenamiento del Modelo** | ☁️ **En la Nube** (Ej: Amazon SageMaker) | 
| **Actualización del Modelo** | ☁️ **Desde la Nube** (Se entrena y se despliega a los dispositivos) |
| **Inferencia en Tiempo Real** | 📱 **En el Dispositivo Edge** (Ejecución de la predicción) |
| **Envío de Logs y Métricas** | ☁️ **Hacia la Nube** (Para monitoreo y análisis, sin urgencia) |

## 3. Servicios de AWS para Edge Computing

AWS ofrece un conjunto de herramientas para construir, desplegar y gestionar soluciones de Machine Learning en el borde.

### AWS IoT Greengrass

Es un servicio que extiende las capacidades de AWS a los dispositivos físicos, permitiéndoles actuar de forma local sobre los datos que generan, mientras siguen usando la nube para la gestión, análisis y almacenamiento duradero.

#### Casos de Uso
- **Inteligencia en el Borde**: Detección de anomalías en agricultura de precisión.
- **Gestión de Aplicaciones**: Despliegue de aplicaciones en flotas de dispositivos.
- **Control de Flotas**: Operación remota o local de dispositivos mediante protocolos como MQTT.
- **Procesamiento Local**: Recopilar, agregar y filtrar datos en el propio dispositivo.

### Amazon SageMaker Neo

Es una capacidad de Amazon SageMaker que permite optimizar modelos de Machine Learning para que se ejecuten más rápido en instancias de la nube y en dispositivos de borde, sin pérdida de precisión.

#### Casos de Uso
- **Optimizar para Inferencia Rápida**: Hace que los modelos de TensorFlow, PyTorch, etc., sean más veloces.
- **Despliegue en el Borde**: Compila y optimiza modelos para ejecutarse en teléfonos, cámaras y dispositivos IoT.
- **Portabilidad del Modelo**: Convierte modelos entre diferentes frameworks y plataformas de hardware.
- **Compresión de Modelos**: Reduce significativamente el tamaño del modelo (mediante cuantización y poda) para disminuir costos de almacenamiento y tiempos de carga.
