# Domain 3: Deploying and Orchestrating Machine Learning Workflows

Welcome to the third domain of this learning plan, focusing on the role and responsibilities of a machine learning engineer. At this stage in the ML lifecycle, you have a trained, tuned, and tested model. Now, it's time to deploy your model into a production environment. In these next three courses, you will learn about the deployment and orchestration of ML workflows.

Domain 3 consists of three parts:
1.  **Selecting a Deployment Infrastructure**
2.  **Creating and Scripting Infrastructure**
3.  **Automating Deployment**

---

## Course 1: Selecting a Deployment Infrastructure

### Course Overview

This course provides a comprehensive understanding of model deployment. You will be introduced to fundamental deployment concepts, the essential components of a production infrastructure, and guidance on selecting the best orchestration services for ML workflows. This course compares and contrasts tools and services from Amazon Web Services (AWS) that you can use during the deployment phase of the ML lifecycle.

It’s essential to understand the performance-cost balance of your compute environment relative to your specific use case. You will learn about compute options for deploying and running ML models effectively.

The course also covers inference infrastructure. You will learn how to select the best deployment target, the appropriate environment for training and inference, and how to differentiate between on-demand and provisioned resources. Finally, you will review how to provision compute resources in production and test environments.

### Learning Objectives

In this course, you will learn to:

- Define model deployment in the ML pipeline.
- Describe a production infrastructure and its components.
- Compare and contrast orchestration services for ML workflows.
- Describe deployment infrastructure design considerations.
- Select the best deployment target based on key benefits.
- Describe ML model deployment strategies and their endpoint requirements.
- Select the best model deployment hosting strategies based on key benefits.
- Select multi-model or multi-container deployments based on key benefits.
- Select the best container option based on key benefits.
- List and describe AWS compute instance types for ML solutions.
- Select the best compute environment for training and inference based on specific requirements.
- Differentiate between on-demand and provisioned resources for performance and scaling issues.
- Describe how to provision compute resources in production and test environments.
- Describe methods for optimizing models on edge devices.

## Course 2: Creating and Scripting Infrastructure

### Course Overview

In the second course, you will learn how to build scalable, maintainable, and cost-efficient ML solutions using Infrastructure as Code (IaC), AWS CloudFormation, AWS container services, and auto-scaling. You will learn to provision resources programmatically, deploy and host models with Amazon SageMaker, and use AWS services to support DevOps and optimize performance. The goal is to give you the skills you need to create robust ML solutions and systems efficiently.

---

## Course 3: Automating Deployment

### Course Overview

In the final course of this domain, you will explore automated orchestration tools for establishing Continuous Integration and Continuous Delivery (CI/CD) pipelines. This course introduces MLOps, a methodology built on applying DevOps practices and CI/CD principles to ML workloads. You will also learn about deployment infrastructure and automation strategies, focusing on risk mitigation and performance enhancements in production environments. Finally, this course covers building and integrating mechanisms to retrain models, which is essential for accommodating new data or updates to model code.
