# AWS CloudFormation for Machine Learning

## 1. Overview

**AWS CloudFormation** is a declarative IaC service that provisions AWS resources through template files. For ML applications, it enables repeatable, version-controlled deployment of infrastructure stacks.

**Key Concepts:**
- **Template:** JSON/YAML file defining resources and configurations
- **Stack:** Collection of resources managed as a single unit
- **Change Set:** Preview of proposed changes before applying

**Benefits:**
- Declarative syntax with automatic dependency management
- Native AWS integration (all services including SageMaker)
- Atomic operations with automatic rollback on failure
- Drift detection for manual changes
- Free to use (pay only for resources)

## 2. Template Structure

CloudFormation templates have 7 sections (only Resources is required):

### 2.1 Core Sections

```yaml
AWSTemplateFormatVersion: '2010-09-09'
Description: 'ML infrastructure for sentiment analysis'

Parameters:
  InstanceType:
    Type: String
    Default: ml.m5.large
    AllowedValues: [ml.m5.large, ml.m5.xlarge, ml.p3.2xlarge]

Mappings:
  RegionMap:
    us-east-1:
      XGBoostImage: '683313688378.dkr.ecr.us-east-1.amazonaws.com/sagemaker-xgboost:1.5-1'
    us-west-2:
      XGBoostImage: '246618743249.dkr.ecr.us-west-2.amazonaws.com/sagemaker-xgboost:1.5-1'

Conditions:
  IsProduction: !Equals [!Ref Environment, 'production']

Resources:
  SageMakerModel:
    Type: AWS::SageMaker::Model
    Properties:
      ModelName: sentiment-model
      PrimaryContainer:
        Image: !FindInMap [RegionMap, !Ref 'AWS::Region', XGBoostImage]
        ModelDataUrl: !Ref ModelDataUrl
      ExecutionRoleArn: !GetAtt SageMakerRole.Arn

Outputs:
  EndpointName:
    Value: !GetAtt SageMakerEndpoint.EndpointName
    Export:
      Name: !Sub '${AWS::StackName}-EndpointName'
```

### 2.2 Intrinsic Functions

| Function | Purpose | Example |
|----------|---------|---------|
| `!Ref` | Reference parameter/resource | `!Ref BucketName` |
| `!GetAtt` | Get resource attribute | `!GetAtt Role.Arn` |
| `!FindInMap` | Lookup in Mappings | `!FindInMap [RegionMap, !Ref 'AWS::Region', Image]` |
| `!Sub` | String substitution | `!Sub 's3://${Bucket}/model.tar.gz'` |
| `!Join` | Concatenate strings | `!Join ['/', ['/aws/sagemaker', !Ref Name]]` |

## 3. Complete Example: SageMaker Endpoint

```yaml
AWSTemplateFormatVersion: '2010-09-09'
Description: 'SageMaker endpoint with monitoring'

Parameters:
  ModelName:
    Type: String
    Default: sentiment-analysis-model
  InstanceType:
    Type: String
    Default: ml.m5.large
  InitialInstanceCount:
    Type: Number
    Default: 2

Mappings:
  RegionMap:
    us-east-1:
      XGBoostImage: '683313688378.dkr.ecr.us-east-1.amazonaws.com/sagemaker-xgboost:1.5-1'
    us-west-2:
      XGBoostImage: '246618743249.dkr.ecr.us-west-2.amazonaws.com/sagemaker-xgboost:1.5-1'

Resources:
  ModelArtifactsBucket:
    Type: AWS::S3::Bucket
    Properties:
      BucketName: !Sub '${AWS::StackName}-artifacts-${AWS::AccountId}'
      VersioningConfiguration:
        Status: Enabled
      BucketEncryption:
        ServerSideEncryptionConfiguration:
          - ServerSideEncryptionByDefault:
              SSEAlgorithm: AES256

  SageMakerExecutionRole:
    Type: AWS::IAM::Role
    Properties:
      AssumeRolePolicyDocument:
        Statement:
          - Effect: Allow
            Principal:
              Service: sagemaker.amazonaws.com
            Action: sts:AssumeRole
      ManagedPolicyArns:
        - arn:aws:iam::aws:policy/AmazonSageMakerFullAccess
      Policies:
        - PolicyName: S3Access
          PolicyDocument:
            Statement:
              - Effect: Allow
                Action: [s3:GetObject, s3:PutObject, s3:ListBucket]
                Resource:
                  - !GetAtt ModelArtifactsBucket.Arn
                  - !Sub '${ModelArtifactsBucket.Arn}/*'

  SageMakerModel:
    Type: AWS::SageMaker::Model
    Properties:
      ModelName: !Ref ModelName
      PrimaryContainer:
        Image: !FindInMap [RegionMap, !Ref 'AWS::Region', XGBoostImage]
        ModelDataUrl: !Sub 's3://${ModelArtifactsBucket}/model.tar.gz'
      ExecutionRoleArn: !GetAtt SageMakerExecutionRole.Arn

  EndpointConfig:
    Type: AWS::SageMaker::EndpointConfig
    Properties:
      ProductionVariants:
        - VariantName: AllTraffic
          ModelName: !GetAtt SageMakerModel.ModelName
          InitialInstanceCount: !Ref InitialInstanceCount
          InstanceType: !Ref InstanceType
      DataCaptureConfig:
        EnableCapture: true
        InitialSamplingPercentage: 100
        DestinationS3Uri: !Sub 's3://${ModelArtifactsBucket}/data-capture'

  SageMakerEndpoint:
    Type: AWS::SageMaker::Endpoint
    Properties:
      EndpointName: !Sub '${ModelName}-endpoint'
      EndpointConfigName: !GetAtt EndpointConfig.EndpointConfigName

  EndpointAlarm:
    Type: AWS::CloudWatch::Alarm
    Properties:
      AlarmName: !Sub '${ModelName}-high-errors'
      MetricName: ModelInvocation4XXErrors
      Namespace: AWS/SageMaker
      Statistic: Sum
      Period: 300
      EvaluationPeriods: 2
      Threshold: 10
      ComparisonOperator: GreaterThanThreshold
      Dimensions:
        - Name: EndpointName
          Value: !GetAtt SageMakerEndpoint.EndpointName

Outputs:
  EndpointName:
    Value: !GetAtt SageMakerEndpoint.EndpointName
    Export:
      Name: !Sub '${AWS::StackName}-EndpointName'
  InvokeUrl:
    Value: !Sub 'https://runtime.sagemaker.${AWS::Region}.amazonaws.com/endpoints/${SageMakerEndpoint}/invocations'
```

**Key Features:** Parameters for customization, region-specific mappings, automatic dependency ordering (Bucket → Role → Model → Config → Endpoint), data capture, CloudWatch monitoring.

## 4. Stack Operations

### 4.1 CLI Commands

**Create:**
```bash
aws cloudformation create-stack \
  --stack-name ml-endpoint-prod \
  --template-body file://template.yaml \
  --parameters ParameterKey=InstanceType,ParameterValue=ml.m5.xlarge \
  --capabilities CAPABILITY_NAMED_IAM
```

**Update with Change Set:**
```bash
# Preview changes
aws cloudformation create-change-set \
  --stack-name ml-endpoint-prod \
  --change-set-name update-instances \
  --template-body file://template-updated.yaml

# Review
aws cloudformation describe-change-set \
  --stack-name ml-endpoint-prod \
  --change-set-name update-instances

# Apply
aws cloudformation execute-change-set \
  --stack-name ml-endpoint-prod \
  --change-set-name update-instances
```

**Delete:**
```bash
aws cloudformation delete-stack --stack-name ml-endpoint-prod
```

### 4.2 Atomic Operations

All resources must provision successfully. On failure, CloudFormation automatically rolls back:

**Example:** Stack with S3, IAM, Model, Config, Endpoint. If Endpoint fails (quota exceeded), CloudFormation deletes Config, Model, IAM, and S3.

**Prevent deletion of stateful resources:**
```yaml
Resources:
  Database:
    Type: AWS::RDS::DBInstance
    DeletionPolicy: Retain  # Keep on stack deletion
```

## 5. Layered Architecture

Organize stacks by lifecycle and ownership:

| Layer | Resources | Lifecycle | Owner |
|-------|-----------|-----------|-------|
| **1. Identity** | IAM roles, users, policies | Rarely changes | Security team |
| **2. Network** | VPC, subnets, security groups | Infrequent | Platform team |
| **3. Shared** | S3 buckets, ECR, databases | Moderate | ML platform team |
| **4. Backend** | SageMaker endpoints, Lambda | Frequent | ML engineering |
| **5. Frontend** | CloudFront, web servers | Frequent | Application team |

**Benefits:** Separation of concerns, reduced blast radius, reusability, independent updates.

## 6. Cross-Stack References

Share resources between stacks using exports/imports.

**Network Stack (exports):**
```yaml
Outputs:
  VPCId:
    Value: !Ref VPC
    Export:
      Name: !Sub '${AWS::StackName}-VPC'
  SecurityGroupId:
    Value: !GetAtt SageMakerSecurityGroup.GroupId
    Export:
      Name: !Sub '${AWS::StackName}-SecurityGroup'
```

**SageMaker Stack (imports):**
```yaml
Parameters:
  NetworkStackName:
    Type: String
    Default: ml-network-stack

Resources:
  SageMakerModel:
    Type: AWS::SageMaker::Model
    Properties:
      VpcConfig:
        SecurityGroupIds:
          - !ImportValue !Sub '${NetworkStackName}-SecurityGroup'
        Subnets:
          - !ImportValue !Sub '${NetworkStackName}-PrivateSubnet'
```

**Limitations:** Export names must be unique per region. Cannot delete a stack if its exports are referenced.

## 7. Best Practices

### 7.1 Template Organization
- Use nested stacks for complex infrastructure
- Parameterize environment-specific values
- Use mappings for region-specific resources

### 7.2 Security
- Never hardcode credentials
- Use IAM roles with least privilege
- Enable encryption (S3, RDS, EBS)
- Store secrets in AWS Secrets Manager

### 7.3 Version Control
- Store templates in Git
- Use semantic versioning
- Tag deployments with commit SHAs

### 7.4 Testing
- Validate: `aws cloudformation validate-template`
- Lint: `cfn-lint template.yaml`
- Test in staging before production
- Use change sets to preview updates

### 7.5 Monitoring
- Enable CloudTrail for API calls
- Set CloudWatch alarms for stack failures
- Use drift detection regularly

## 8. Summary

**CloudFormation** is AWS's native declarative IaC tool for provisioning ML infrastructure.

**Key Capabilities:**
- Declarative YAML/JSON templates
- Automatic dependency management
- Atomic operations with rollback
- Change sets for safe updates
- Cross-stack references
- Drift detection

**When to Use:**
- ✅ AWS-only deployments
- ✅ Need native AWS service integration
- ✅ Teams comfortable with YAML/JSON
- ✅ Regulatory/audit requirements

**vs. Other Tools:**
- **Terraform:** Multi-cloud support, larger community
- **AWS CDK:** Programming languages (generates CloudFormation)
- **Pulumi:** Programming languages with multi-cloud
